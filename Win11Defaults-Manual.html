1. Введение

Win11 Defaults Manager — утилита для Windows 10/11, которая возвращает недостающую функцию: возможность назначить приложение «по умолчанию» для всех поддерживаемых расширений и протоколов одной кнопкой.

Что умеет программа

  • Массовая установка ассоциаций — одной кнопкой назначает приложению все его расширения (в Windows 11 это приходится делать вручную для каждого формата)
  • Управление UCPD.sys — отключает/включает защитный драйвер Microsoft, блокирующий изменение ассоциаций
  • Два метода применения: мгновенный (SetUserFTA) и официальный (политика Microsoft)
  • Пакетное развёртывание — экспорт/импорт профилей в JSON для применения на множестве ПК
  • Цветовая индикация — сразу видно, что уже настроено, а что нет

Для кого эта программа

  • Домашние пользователи — быстро настроить ассоциации после установки Windows
  • Системные администраторы — массовое развёртывание одинаковых настроек на парке ПК
  • IT-специалисты — тонкая настройка ассоциаций без редактирования реестра вручную

2. Быстрый старт

Для домашнего пользователя (5 минут)

  1. Запустите Win11Defaults.exe (двойной клик)
  2. Перейдите на вкладку «UCPD.sys» → нажмите «Отключить UCPD» → согласитесь на перезагрузку
  3. После перезагрузки снова откройте программу, перейдите на вкладку «Приложения»
  4. Выберите нужную программу слева (например, WinRAR, AIMP, Firefox)
  5. Нажмите большую синюю кнопку «По умолчанию»
  6. Готово! Все расширения этого приложения назначены
  7. (Опционально) Вернитесь на вкладку UCPD.sys → «Восстановить UCPD» → перезагрузка

Для администратора (пакетное развёртывание)

  1. Настройте ассоциации на эталонном ПК через GUI
  2. Экспортируйте профиль: кнопка «Экспорт профиля...» → сохраните profile.json
  3. Скопируйте папку с Win11DefaultsCLI.exe и profile.json на целевые ПК
  4. Запустите из командной строки: 
    Win11DefaultsCLI.exe --disable-ucpd --reboot
:: после перезагрузки
Win11DefaultsCLI.exe
Win11DefaultsCLI.exe --enable-ucpd --reboot

Что такое значения Start?

Start — это режим запуска драйвера Windows (аналогично services.msc):

ЗначениеНазваниеОписание
0BootЗагружается при загрузке ядра Windows
1SystemЗагружается при загрузке системы
2AutomaticЗапускается автоматически при загрузке Windows
3ManualЗапускается вручную ПО УМОЛЧАНИЮ для UCPD
4DisabledОтключён, не запускается НУЖНО для работы SetUserFTA
💡 Нормальное состояние Windows
Start: 3 (Manual), драйвер запущен. Для работы программы нужно: Start: 4 (Disabled), драйвер не запущен.

4. Два движка применения ассоциаций

Программа использует два независимых метода записи ассоциаций. Выбор движка осуществляется в выпадающем списке на вкладке «Приложения».

Движок №1: SetUserFTA (мгновенный)

Как работает

Записывает в реестр пользователя (HKCU\...\FileExts\.ext\UserChoice) корректный ProgId вместе с криптографическим хэшем. Хэш вычисляется по формуле Microsoft (SID пользователя + расширение + ProgID + время записи). Без правильного хэша Windows игнорирует запись.

Требования

  • UCPD.sys должен быть отключён (иначе драйвер заблокирует запись)
  • Файл SetUserFTA.exe (встроен в собранный exe при компиляции)

Плюсы и минусы

✅ Плюсы❌ Минусы
Работает мгновенно, без перезагрузки Требует отключения UCPD (снижает защиту системы)
Не перекрывает ручной выбор пользователя в будущем Обновления Windows могут вернуть UCPD
Не оставляет следов в системе Нужно один раз перезагрузиться после отключения UCPD

Движок №2: Политика DefaultAssociationsConfiguration (официальный)

Как работает

Создаёт XML-файл со списком ассоциаций и прописывает путь к нему в групповую политику: HKLM\SOFTWARE\Policies\Microsoft\Windows\System\DefaultAssociationsConfiguration. Windows применяет этот XML при каждом входе пользователя в систему.

Требования

  • Права администратора (запись в HKLM)
  • UCPD отключать не нужно

Плюсы и минусы

✅ Плюсы❌ Минусы
Официальный механизм MicrosoftПрименяется только после выхода и входа в систему
Не требует отключения UCPDЖёстко перекрывает ручной выбор пользователя
Живучий — переприменяется при каждом входеОставляет файл C:\ProgramData\Win11DefaultsManager\DefaultAssociations.xml
Работает для всех пользователей на ПКТребует прав администратора

5. Управление UCPD.sys

Что такое UCPD.sys?

UCPD (User Choice Protection Driver) — защитный драйвер Microsoft, встроенный в Windows 10/11. Его единственная задача: не дать программам менять ассоциации файлов без ведома пользователя.

Драйвер появился после того, как многие программы (особенно браузеры и медиаплееры) начали агрессивно перехватывать ассоциации при установке.

Как работает UCPD?

  1. Программа пытается записать в HKCU\...\FileExts\.ext\UserChoice новый ProgID
  2. UCPD перехватывает операцию записи
  3. Драйвер проверяет, инициировано ли изменение пользователем через стандартный диалог Windows
  4. Если нет — запись блокируется или сбрасывается

Состояния UCPD

СостояниеЗащитаSetUserFTA
АКТИВЕН (по умолчанию) ✅ Включена ❌ Не работает
ОТКЛЮЧЁН ⚠️ Снята ✅ Работает мгновенно

Как отключить UCPD?

Через GUI: Вкладка «UCPD.sys» → кнопка «Отключить UCPD» → подтвердить → перезагрузить ПК.

Через CLI:

Win11DefaultsCLI.exe --disable-ucpd --reboot

Что происходит при отключении

  1. HKLM\SYSTEM\CurrentControlSet\Services\UCPD\Start → 4 (Disabled)
  2. Отключается задача \Microsoft\Windows\AppxDeploymentClient\UCPD velocity
  3. Создаётся резервная копия ветки реестра в %APPDATA%\Win11DefaultsManager\

Как восстановить UCPD?

Win11DefaultsCLI.exe --enable-ucpd --reboot
✅ Важно
После восстановления UCPD ваши ассоциации останутся (они уже записаны с правильным хэшем). UCPD просто не даст их изменить без вашего ведома.

Что если задача UCPD velocity не отключается?

Иногда задача защищена и не отключается даже от имени администратора. Решение:

  1. Скачайте PsExec с сайта Microsoft Sysinternals
  2. Запустите командную строку от имени SYSTEM: 
    psexec -s -i powershell
  3. В открывшемся окне PowerShell выполните: 
    Disable-ScheduledTask -TaskPath '\Microsoft\Windows\AppxDeploymentClient\' `
  -TaskName 'UCPD velocity'

6. Пакетный режим (CLI)

Пакетный режим предназначен для автоматического применения настроек без графического интерфейса. Идеально для развёртывания на множестве ПК.

Сборка CLI-версии

Для пакетного режима нужна версия с консольным окном (чтобы видеть вывод):

pyinstaller -F --uac-admin --add-data "SetUserFTA.exe;." ^
            --name Win11DefaultsCLI win11_defaults.py

Ключ -F создаёт один exe-файл, --add-data встраивает SetUserFTA.exe внутрь.

📦 Результат сборки
  • Win11Defaults.exe — GUI-версия (без консоли, для двойного клика)
  • Win11DefaultsCLI.exe — CLI-версия (с консолью, для командной строки)

Ключи командной строки

КлючОписаниеАдмин
--helpПоказать справкуНет
--export [файл]Экспортировать текущие ассоциации в JSONНет
--apply [файл]Применить JSON-профильЗависит от движка
--engine suftaИспользовать SetUserFTA (по умолчанию)Нет (для HKCU)
--engine policyИспользовать официальную политику MicrosoftДа
--disable-ucpdОтключить UCPD.sysДа
--enable-ucpdВосстановить UCPD.sysДа
--disable-policyСнять политику DefaultAssociationsConfigurationДа
--rebootПерезагрузить ПК после выполнения командДа
--sufta PATHУказать путь к SetUserFTA.exe (сохраняется в конфиг)Нет

Автопоиск profile.json

Если ключ --apply указан без аргумента или не указан вовсе, программа ищет файл profile.json в той же папке, где лежит exe:

# Эти команды эквивалентны:
Win11DefaultsCLI.exe --apply
Win11DefaultsCLI.exe --apply profile.json
Win11DefaultsCLI.exe

Примеры команд

Экспорт профиля

# Сохранить в текущую папку
Win11DefaultsCLI.exe --export profile.json

# Сохранить в конкретное место
Win11DefaultsCLI.exe --export C:\share\profile.json

Применение профиля

# Применить profile.json из папки программы (SetUserFTA)
Win11DefaultsCLI.exe

# Явно указать файл
Win11DefaultsCLI.exe --apply profile.json

# Через политику
Win11DefaultsCLI.exe --apply profile.json --engine policy

Управление UCPD

# Отключить и перезагрузить
Win11DefaultsCLI.exe --disable-ucpd --reboot

# Восстановить
Win11DefaultsCLI.exe --enable-ucpd --reboot

# Только отключить (без перезагрузки)
Win11DefaultsCLI.exe --disable-ucpd

7. Сценарии развёртывания

Сценарий 1: Настройка своего ПК (домашнее использование)

Цель: Быстро настроить ассоциации для всех установленных программ.

  1. Запустите Win11Defaults.exe
  2. Вкладка UCPD.sys → «Отключить UCPD» → перезагрузка
  3. После перезагрузки откройте программу снова
  4. Вкладка Приложения → выберите программу → «По умолчанию»
  5. Повторите для всех нужных программ
  6. (Опционально) Вкладка UCPD.sys → «Восстановить UCPD» → перезагрузка

Время: 5–10 минут

Сценарий 2: Развёртывание на 10–50 ПК (малый бизнес)

Цель: Одинаковые ассоциации на всех рабочих станциях.

Подготовка (на эталонном ПК)

  1. Установите все нужные программы
  2. Настройте ассоциации через GUI
  3. Экспортируйте профиль: «Экспорт профиля...» → profile.json
  4. Скопируйте Win11DefaultsCLI.exe и profile.json на флешку/сетевую шару

Развёртывание (на каждом ПК)

Вариант А — через SetUserFTA (рекомендуется):

# Шаг 1. Отключить UCPD (требует перезагрузки)
\\server\share\Win11DefaultsCLI.exe --disable-ucpd --reboot

# Шаг 2. После перезагрузки применить профиль
\\server\share\Win11DefaultsCLI.exe

# Шаг 3. (Опционально) Восстановить UCPD
\\server\share\Win11DefaultsCLI.exe --enable-ucpd --reboot

Вариант Б — через политику (быстрее, но перекрывает ручной выбор):

# Одна команда + перезагрузка
\\server\share\Win11DefaultsCLI.exe --apply profile.json --engine policy
shutdown /r /t 0

Время: 15–30 минут на ПК (включая перезагрузки)

Сценарий 3: Массовое развёртывание через GPO (крупная организация)

Цель: Автоматическое применение при загрузке ПК.

Шаг 1. Подготовка пакета

Создайте папку на сетевой шаре:

\\domain.local\SYSVOL\domain.local\scripts\Win11Defaults\
├── Win11DefaultsCLI.exe
├── profile.json
└── deploy.bat

Содержимое deploy.bat:

@echo off
cd /d "%~dp0"

:: Проверяем, отключён ли UCPD
sc query ucpd | find "RUNNING" >nul
if %errorlevel%==0 (
    echo [%date% %time%] UCPD активен, отключаем...
    Win11DefaultsCLI.exe --disable-ucpd
    shutdown /r /t 30 /c "Отключение UCPD. Перезагрузка через 30 секунд."
    exit /b
)

:: Проверяем, применён ли профиль
if not exist "C:\ProgramData\Win11DefaultsManager\applied.flag" (
    echo [%date% %time%] Применяем профиль...
    Win11DefaultsCLI.exe --engine sufta
    echo. > "C:\ProgramData\Win11DefaultsManager\applied.flag"
    echo [%date% %time%] Профиль применён.
) else (
    echo [%date% %time%] Профиль уже применён, пропускаем.
)

Шаг 2. Настройка GPO

  1. Откройте Group Policy Management
  2. Создайте новую GPO или отредактируйте существующую
  3. Перейдите: Computer Configuration → Policies → Windows Settings → Scripts (Startup/Shutdown)
  4. Добавьте deploy.bat как Startup Script
  5. Убедитесь, что скрипт запускается от имени SYSTEM (по умолчанию)

Шаг 3. Применение

  1. При следующей загрузке ПК: UCPD отключится → ПК перезагрузится
  2. После перезагрузки профиль применится → создастся флаг
  3. При следующих загрузках ничего не произойдёт (флаг есть)

Сценарий 4: Развёртывание через Intune/SCCM

Цель: Применение через современные системы управления.

Шаг 1. Создание пакета

Создайте .intunewin пакет (Intune) или приложение (SCCM) со следующими файлами:

Win11DefaultsCLI.exe
profile.json
install.cmd

Содержимое install.cmd:

@echo off
cd /d "%~dp0"

:: Применяем через политику (работает из системного контекста)
Win11DefaultsCLI.exe --apply profile.json --engine policy

:: Возвращаем код успеха
exit /b 0

Шаг 2. Настройка Intune

  1. Microsoft Intune → Apps → Add → Windows app (Win32)
  2. Загрузите .intunewin пакет
  3. Program install command: install.cmd
  4. Uninstall command: Win11DefaultsCLI.exe --disable-policy
  5. Detection rule: проверьте наличие файла C:\ProgramData\Win11DefaultsManager\DefaultAssociations.xml
  6. Assign to нужным группам устройств
⚠️ Важно
Из системного контекста (SYSTEM) нельзя писать в HKCU конкретного пользователя, поэтому используется движок policy (пишет в HKLM).

Сценарий 5: Экспорт и импорт между разными ПК

Цель: Перенести настройки ассоциаций с одного ПК на другой.

  1. На исходном ПК: Win11DefaultsCLI.exe --export C:\temp\my_profile.json
  2. Перенесите файл на целевой ПК
  3. На целевом ПК: Win11DefaultsCLI.exe --apply C:\temp\my_profile.json
⚠️ Ограничения
Профиль содержит ProgID конкретных программ. Если на целевом ПК программа не установлена или имеет другую версию, ассоциации не применятся. Пути к exe в профиле информационные, на применение не влияют.

Общие вопросы

В: Программа безопасна? Не сломает ли она Windows?

О: Программа работает только с реестром пользователя (HKCU) или групповой политикой (HKLM). Она не модифицирует системные файлы. Все изменения обратимы:

  • Ассоциации можно сбросить через «Параметры Windows»
  • UCPD можно восстановить кнопкой «Восстановить UCPD»
  • Резервные копии реестра сохраняются автоматически

В: Почему нужно отключать UCPD? Это не опасно?

О: UCPD — защитный механизм от вредоносного ПО, которое меняет ассоциации без ведома пользователя. Отключая его, вы снижаете защиту. Рекомендуется:

  1. Отключить UCPD только на время настройки
  2. Применить ассоциации
  3. Восстановить UCPD

В: Можно ли использовать программу для UWP-приложений (из Microsoft Store)?

О: Нет. UWP-приложения используют другой механизм ассоциаций (AppX), который не поддерживается данной утилитой. Для них используйте стандартные «Параметры Windows» → «Приложения» → «Приложения по умолчанию».

В: Программа работает на Windows 10?

О: Да, программа работает на Windows 10 (1809 и новее) и Windows 11. UCPD.sys присутствует в обеих системах.

Технические вопросы

В: Что такое ProgID?

О: ProgID (Programmatic Identifier) — строковый идентификатор программы в реестре Windows. Например:

  • WinRAR — для WinRAR
  • AIMP.AssocFile.MP3 — для AIMP (формат MP3)
  • Applications\firefox.exe — для Firefox

В: Почему в колонке «Текущая программа» иногда написано «(не задано)», хотя в Windows ассоциация есть?

О: Программа показывает только выбор текущего пользователя (из HKCU\...\UserChoice). Если ассоциация задана глобально для всех пользователей (через HKCR\.ext), программа считает её и применит поверх.

В: SetUserFTA выдаёт ошибки при применении. Что делать?

О: Проверьте:

  1. UCPD.sys отключён? (вкладка UCPD.sys → статус должен быть зелёным)
  2. ПК был перезагружен после отключения UCPD?
  3. SetUserFTA.exe встроен в exe? (проверьте сборку с --add-data)

В: Можно ли отключить UCPD навсегда?

О: Технически да (Start: 4), но:

  • Обновления Windows могут вернуть UCPD
  • Задача UCPD velocity может реактивировать драйвер
  • Рекомендуется восстанавливать UCPD после настройки

В: Почему политика перекрывает ручной выбор пользователя?

О: Это особенность механизма DefaultAssociationsConfiguration. Windows применяет политику при каждом входе, перезаписывая пользовательские настройки. Это сделано для корпоративной среды, где нужно гарантировать одинаковые настройки.

В: Можно ли применить профиль только для некоторых расширений?

О: В GUI — да, снимите галочки с ненужных расширений и нажмите «Применить отмеченные». В CLI — отредактируйте profile.json, удалив ненужные записи из секции apps.

Вопросы по развёртыванию

В: Как развернуть на 100+ ПК?

О: Используйте сценарий 3 (GPO) или сценарий 4 (Intune/SCCM). Ручное развёртывание на таком количестве ПК нецелесообразно.

В: Можно ли применять профиль из сетевого пути?

О: Да, программа поддерживает UNC-пути:

Win11DefaultsCLI.exe --apply \\server\share\profile.json

Убедитесь, что у пользователя есть права на чтение сетевой папки.

В: Что делать, если на целевом ПК не установлены некоторые программы из профиля?

О: Программа пропустит расширения, для которых не найден ProgID. В журнале будет сообщение:

пропуск .xyz: ProgID 'SomeApp.AssocFile.XYZ' не зарегистрирован

В: Как откатить изменения, применённые через политику?

О: Запустите:

Win11DefaultsCLI.exe --disable-policy

Или удалите файл C:\ProgramData\Win11DefaultsManager\DefaultAssociations.xml и запись в реестре HKLM\SOFTWARE\Policies\Microsoft\Windows\System\DefaultAssociationsConfiguration.

Вопросы по сборке

В: Как собрать exe из исходного кода?

  1. Установите Python 3.9+ и PyInstaller: 
    pip install pyinstaller
  2. Скачайте SetUserFTA.exe с kolbi.cz
  3. Положите SetUserFTA.exe рядом с win11_defaults.py
  4. Соберите GUI-версию: 
    pyinstaller -F -w --uac-admin --add-data "SetUserFTA.exe;." --name Win11Defaults win11_defaults.py
  5. Соберите CLI-версию: 
    pyinstaller -F --uac-admin --add-data "SetUserFTA.exe;." --name Win11DefaultsCLI win11_defaults.py

В: Антивирус удаляет собранный exe. Что делать?

О: PyInstaller + --uac-admin + работа с реестром = эвристика антивируса. Решения:

  • Добавьте папку с exe в исключения антивируса
  • Подпишите код цифровой подписью (требуется сертификат)
  • Используйте -D вместо -F (создаёт папку вместо одного файла, реже детектируется)

В: Почему GUI-версия запускается долго (5–10 секунд)?

О: Ключ -F упаковывает всё в один exe. При запуске PyInstaller распаковывает содержимое во временную папку (%TEMP%\_MEIxxxxx). Это нормально. Для ускорения используйте -D (создаёт папку с файлами).

В: Как проверить, что собранный exe рабочий?

  • python -m py_compile win11_defaults.py — без ошибок
  • Win11Defaults.exe — открывается GUI, список приложений заполнен
  • Win11DefaultsCLI.exe --help — показывает справку
  • Win11DefaultsCLI.exe --export profile.json — создаёт файл
  • Win11DefaultsCLI.exe (без ключей) — применяет profile.json рядом
  • Вкладка UCPD.sys показывает зелёный/красный статус
  • Кнопка «По умолчанию» реально меняет ассоциацию (проверьте в Проводнике: правый клик → «Открыть с помощью»)

Приложение Б: Командная шпаргалка

Быстрые команды

# Справка
Win11DefaultsCLI.exe --help

# Экспорт профиля
Win11DefaultsCLI.exe --export profile.json

# Применение профиля (SetUserFTA)
Win11DefaultsCLI.exe --apply profile.json

# Применение профиля (политика)
Win11DefaultsCLI.exe --apply profile.json --engine policy

# Отключить UCPD + перезагрузка
Win11DefaultsCLI.exe --disable-ucpd --reboot

# Восстановить UCPD + перезагрузка
Win11DefaultsCLI.exe --enable-ucpd --reboot

# Снять политику
Win11DefaultsCLI.exe --disable-policy

# Применить profile.json из папки программы
Win11DefaultsCLI.exe

Полные сценарии

Сценарий А: SetUserFTA (рекомендуется)

Win11DefaultsCLI.exe --disable-ucpd --reboot
:: после перезагрузки
Win11DefaultsCLI.exe
Win11DefaultsCLI.exe --enable-ucpd --reboot

Сценарий Б: Политика (быстро)

Win11DefaultsCLI.exe --apply profile.json --engine policy
shutdown /r /t 0
